## Risks

- **Pathspec accuracy:** Some files overlap categories conceptually. The plan groups by logical domain; if a file belongs to multiple groups, it goes into the most relevant stash. Since Git removes stashed files from the working tree, a file can only appear in one stash.
- **Untracked files:** Using `--include-untracked` will capture untracked files but also remove them from disk. The `.kilo/plans/1778406382394-shiny-otter.md` (this plan file) should NOT be included in any stash.
- **Order matters:** Stashes must be created in order since each stash removes its files from the working tree. Running `git status` between stashes confirms this.
- **Branch rename safety:** If remote tracking gets confused after rename, `git branch -u origin/refactor/wave4-parallel-delegation` can fix it.
